ระบบเมนูอาหารแนะนำ คัดกรอง และสุ่มเมนู "Kinraid"

ภาพรวมโปรเจกต์: เว็บไซต์ระบบแนะนำร้านอาหารและเครื่องมือช่วยตัดสินใจสำหรับคนเลือกไม่ได้ พร้อมฟังก์ชันคัดกรองวัตถุดิบที่แพ้และการจัดการอเดอร์

1. ฟังก์ชันของเว็บ:
- แสดงรายการอาหารที่มีทั้งหมด
- ตัวกรองประเภทอาหารที่อาจแพ้
- ระบบสุ่มเมนู เครื่องมือช่วยตัดสินใจสำหรับคนเลือกไม่ได้
- หน้าต่างแสดงวัตถุดิบ เวลาในการทำ และตัวเลือกการปรับแต่งตามชอบ
- แสดงราคา

2. สิ่งที่ฝ่าย User จะได้เห็น:
- ชื่อร้าน + โลโก้
- แถบค้นหา พิมพ์ชื่อเมนูที่ต้องการ
- ปุ่มกรองวัตถุดิบแพ้ เมื่อกดแล้วจะมี Pop-up ให้เลือกปุ่มติ๊กเมนูที่แพ้
- คิดตัง (ระบบคำนวณราคา)
- เบอร์สำหรับติดต่อร้าน

3. องค์ประกอบหน้าเว็บ (ปุ่มต่างๆ):
- เมนูอาหาร รูปภาพ พร้อมราคา
- กดที่เมนูเพื่อดูวัตถุดิบ และ Add-on
- ปุ่มสุ่มเมนูอาหาร
- ปุ่มกรองวัตถุดิบที่แพ้
- ปุ่มค้นหา
- ปุ่มรีเซ็ทตัวกรอง + รีเซ็ทเมนูที่ปรับแต่ง

เครื่องให้อาหารสัตว์เลี้ยงอัตโนมัติ "SMART PET FEEDER"

ภาพรวมโปรเจกต์: ระบบไมโครคอนโทรลเลอร์ (Computer and Embedded Systems) ควบคุมเครื่องให้อาหารสัตว์เลี้ยงอัตโนมัติ[cite: 1] เพื่ออำนวยความสะดวกให้เจ้าของที่ไม่อยู่บ้าน ช่วยให้สัตว์เลี้ยงได้รับอาหารตรงเวลาสม่ำเสมอ

1. ฟังก์ชันและการทำงานของระบบ:
- ระบบนาฬิกาเรียลไทม์แสดงผลผ่าน 7-Segment 6 หลัก (HH:MM:SS) โดยใช้เทคนิค Multiplexing
- จ่ายอาหารอัตโนมัติตามเวลาที่กำหนดไว้ (08:00:00 น. และ 18:00:00 น.)
- ระบบควบคุมมอเตอร์อัจฉริยะผ่าน ADC เพื่อปรับความเร็วการหมุน (Fast / Slow / Stop) ลดการค้างของอาหาร
- ปุ่มปรับตั้งค่าเวลา (Hour, Min, Sec) แบบ Manual Setup

2. ฮาร์ดแวร์และเทคโนโลยีที่ใช้:
- Microcontroller: PIC16F877A
- Display: 7-Segment Display + BCD-to-7Segment Decoder (IC 7447)
- Motor Driver: IC L293D ควบคุมมอเตอร์จ่ายอาหาร
- Programming Language: ภาษา Assembly (จัดการ Interrupt Service Routine และ Register Control)

3. จุดเด่นและข้อดีของโปรเจกต์:
- ใช้ระบบ Interrupt Service Routine ในการนับเวลา ทำให้เวลาเดินตรงและเที่ยงตรงแม้มีการทำงานอื่นอยู่
- ประหยัดการใช้ขา I/O ของไมโครคอนโทรลเลอร์อย่างมีประสิทธิภาพด้วย Multiplexing
- การจ่ายอาหารนุ่มนวล ลดความเสียหายของกลไกด้วยการใช้ ADC ปรับระดับความเร็วมอเตอร์

วงจรกำจัดแถบความถี่ผ่าน (Band-Reject Filter: BRF)

ภาพรวมโปรเจกต์: การศึกษาวิเคราะห์ ออกแบบ และสร้างชิ้นงานแผงวงจรอิเล็กทรอนิกส์จริง (PCB) สำหรับวงจรกำจัดแถบความถี่ผ่านชนิดแอกทีฟ (Active Band-Reject Filter)[cite: 2] เพื่อลดสัญญาณรบกวนในช่วงความถี่ที่ไม่ต้องการและเพิ่มประสิทธิภาพในระบบสื่อสารหรือเครื่องเสียง[cite: 2]

1. การออกแบบและการทำงานของวงจร:
- ออกแบบวงจร Active Filter โดยใช้ Op-Amp LM741 ร่วมกับอุปกรณ์ Passive (ตัวต้านทานและตัวเก็บประจุ)[cite: 2]
- กำหนดความถี่กลาง (Center Frequency: f0) ที่ระดับ 3 kHz[cite: 2]
- กรองแถบความถี่ช่วงสตอปแบนด์ (Stopband) ออกได้อย่างแม่นยำ และยอมให้ความถี่ช่วงพาสแบนด์ (Passband) ผ่านได้[cite: 2]

2. อุปกรณ์และขั้นตอนการทำชิ้นงานจริง (Hardware Realization):
- อุปกรณ์หลัก: IC LM741, C (56nF, 10nF), R (500Ω, 5kΩ, 10kΩ, 15kΩ)[cite: 2]
- ขั้นตอนผลิตแผ่น PCB: ออกแบบลายวงจรผ่านโปรแกรม -> พิมพ์ลายลงกระดาษโฟโต้ -> รีดลายลงแผ่นทองแดง -> กัดแผ่นปริ้นด้วยน้ำยากัด PCB -> เจาะรูด้วยสว่านมือ และบัดกรีอุปกรณ์[cite: 2]
- การทดสอบ: ต่อจ่ายสัญญาณจาก Signal Generator และวัดสัญญาณขา V-out ด้วย Oscilloscope เพื่อเก็บบันทึกความถี่ตอบสนอง[cite: 2]

3. ผลลัพธ์และทักษะที่ได้:
- สามารถผลิตแผงวงจร PCB ที่ใช้งานได้จริงตั้งแต่กระบวนการออกแบบจนถึงประกอบ[cite: 2]
- เข้าใจการคำนวณพารามิเตอร์ของ Active Filter เช่น ค่าแบนด์วิดธ์ (BW) และค่า Q (Quality Factor)[cite: 2]
- เชี่ยวชาญการใช้อุปกรณ์วัดทางอิเล็กทรอนิกส์ (Function Generator, Oscilloscope, Multimeter) ในการทดสอบวงจร[cite: 2]
